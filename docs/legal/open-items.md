# 开放事项 · Open items

## 中文

以下问题无法由文档解决，需要组织负责人或专业人士判断。在解决前，不要对外宣称已完成。

| 事项 | 现状 | 需要做什么 |
| :--- | :--- | :--- |
| 法律主体 | 未登记，属非正式学生团体 | 决定是否登记，或明确以个人身份运营的边界 |
| 互联网信息服务备案 | 站点托管于 GitHub Pages（境外） | 结合服务对象与运营模式，向通信管理部门或律师确认是否需要备案 |
| 商标 | 未检索 | 检索 "Westlake Drawer" 及标识是否与在先权利冲突 |
| 正式联系渠道 | 仅 GitHub issue | 设立并公示一个用于法律通知的邮箱 |
| 贡献者协议签署 | 以提交即视为同意 | 若需正式签署，引入签署流程并留存记录 |
| 个人信息出境 | 数据存于 GitHub（美国） | 评估是否需要履行出境相关程序 |
| 未成年人保护 | 仅作年龄声明 | 若面向未成年人开放，补充监护人同意机制 |
| 内容审核人力 | 无固定值班 | 明确响应通知的负责人与时限 |
| 双因素认证 | 组织设置尚未开启强制 | 在组织设置中启用 |
| 分支保护 | 部分仓库未开启 | 对 `main` 启用保护与必需审核 |

## English

These cannot be settled by documents alone; they need a decision by the project's
leads or by a professional. Until then, do not claim they are done.

| Item | Status | Action needed |
| :--- | :--- | :--- |
| Legal entity | Unregistered informal group | Decide whether to register, or define the limits of operating personally |
| ICP filing | Hosted on GitHub Pages (abroad) | Confirm with the communications authority or a lawyer, based on audience and model |
| Trademark | Not searched | Search "Westlake Drawer" and its marks against prior rights |
| Official contact | GitHub issues only | Establish and publish an address for legal notices |
| CLA signing | Acceptance by submission | Add a signing step with records if formal signatures are needed |
| Cross-border data | Stored on GitHub (US) | Assess whether transfer procedures apply |
| Minors | Age statement only | Add guardian consent if opened to minors |
| Review staffing | No on-call owner | Name who answers notices and within what time |
| Two-factor authentication | Not enforced in organization settings | Enable enforcement |
| Branch protection | Missing on some repositories | Protect `main` with required review |
