# 安全须知 · Security

## 中文

**本站是静态站点。** 只提供文本与图片，不代替你执行代码、不设置分析 Cookie、
不索取账号凭据。页面上的脚本仅用于渲染。

**工具是第三方软件。** [工具](/tools) 下的每个插件与应用都存放在他人的仓库中，
安装后以你的用户权限运行。被列出不等于经过安全审计。安装前请：

- 阅读源码，至少看完安装与卸载步骤；
- 查看仓库的 `SECURITY.md` 与发布记录；
- 优先放在虚拟环境、容器或独立账户中运行；
- 默认认为它能读取你权限内的任何文件。

**密钥。** 任何插件都不需要你的账号密码。API Key 应放在环境变量或系统凭据存储里，
不要写进会提交的文件。若某个工具要求填入 Key，先确认它存在哪里、会不会上传。

**第三方服务。** 部分页面的徽章与图片由外部服务生成，这些服务会收到访问者的
IP 与 User-Agent。索引默认不再内嵌此类资源，但被链接的仓库可能仍有。

**报告漏洞。** 请私下报告：在受影响的仓库使用 GitHub 的 *Report a vulnerability*，
或通过组织联系维护者。不要为未修复的问题公开 issue 复现步骤。

## English

**This site is static.** It serves text and images. It does not run code on your
behalf, set cookies for analytics, or ask for credentials. The only scripts are
the ones needed to render the page.

**Tools are third-party software.** Every plugin and application listed under
[Tools](/tools) lives in someone else's repository and runs with your user
privileges once you install it. Listing is not an audit. Before installing:

- Read the source or at least the install and uninstall steps.
- Check the repository's `SECURITY.md` and its release history.
- Prefer a virtual environment, container, or a separate account.
- Assume it can read any file you can read.

**Secrets.** No plugin needs your account password. API keys belong in
environment variables or the operating system's credential store, never in a
file you commit. If a tool asks for a key, check where it stores it and whether
it is sent anywhere.

**Third-party services.** Badges and images on some pages are generated by
external services, which receive the visitor's IP address and user agent. The
index no longer embeds them by default, but linked repositories may.

**Reporting a vulnerability.** Report privately: use GitHub's *Report a
vulnerability* on the affected repository, or contact a maintainer through the
organization. Do not open a public issue with reproduction steps for an
unfixed problem.
