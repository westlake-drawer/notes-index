# 法律与安全 · Legal & Safety

## 中文

Westlake Drawer 是由学生以个人身份维护的课程笔记与工具索引，**不是西湖大学的官方组织**，
也不是依法登记的社会团体或法人。下列文件共同构成项目的规则体系。

| 文件 | 解决什么问题 |
| :--- | :--- |
| [组织章程与治理](/legal/governance) | 谁维护、谁决策、如何退出与解散 |
| [用户使用条款](/legal/terms) | 你与本站的关系、使用限制、争议解决 |
| [隐私政策](/legal/privacy) | 收集哪些信息、保存多久、你的权利 |
| [版权与许可](/legal/copyright) | 笔记归谁、教师材料边界、第三方许可 |
| [贡献者许可协议](/legal/cla) | 投稿授权范围与权利保证 |
| [侵权通知与反通知](/legal/takedown) | 投诉材料、处理时限、恢复程序 |
| [免责声明](/legal/disclaimer) | 本站承诺什么、不承诺什么 |
| [学术诚信](/legal/academic-integrity) | 作业、考试、科研资料的边界 |
| [第三方工具收录政策](/legal/tool-policy) | 工具如何被收录、标注与下架 |
| [名称与非官方关联](/legal/brand) | 校名、地图、标识的使用边界 |
| [安全政策](/legal/security) | 运行工具的风险、漏洞披露、事故响应 |
| [责任分配](/legal/responsibility) | 贡献者、维护者、工具作者、读者的分工 |

文件的效力顺序：仓库自带的 `LICENSE` / `SECURITY.md` / `NOTICE` > 本页各专项文件 > 概述页。
若某条与法律强制性规定冲突，以法律为准。

## English

Westlake Drawer is a course-note and tools index maintained by students in a
personal capacity. It is **not an official organization of Westlake University**
and not a registered association or legal entity. The documents below form the
project's rule set.

| Document | Resolves |
| :--- | :--- |
| [Governance](/legal/governance) | Who maintains, who decides, how to leave and wind down |
| [Terms of use](/legal/terms) | Your relationship with the site, restrictions, disputes |
| [Privacy policy](/legal/privacy) | What is collected, how long it is kept, your rights |
| [Copyright and licensing](/legal/copyright) | Ownership, instructor material, third-party licences |
| [Contributor licence](/legal/cla) | Scope of the submission licence and warranties |
| [Notice and counter-notice](/legal/takedown) | Complaint materials, timelines, restoration |
| [Disclaimer](/legal/disclaimer) | What the site does and does not promise |
| [Academic integrity](/legal/academic-integrity) | Coursework, exams, research material |
| [Tool listing policy](/legal/tool-policy) | How tools are listed, labelled, removed |
| [Name and affiliation](/legal/brand) | Use of university name, maps, marks |
| [Security](/legal/security) | Risk of running tools, disclosure, incident response |
| [Responsibility](/legal/responsibility) | Who is answerable for what |

Precedence: a repository's own `LICENSE` / `SECURITY.md` / `NOTICE` first, then the
specific document, then this overview. Mandatory law overrides all of them.

## 说明 · Note

These texts are drafted by volunteers from public sources and are **not legal
