# Legal & Safety

Westlake Drawer is a student-run index of course notes and tools. It is not an
official publication of Westlake University, and it is not a party to any
agreement you make with the authors of the material it links to.

| Page | Covers |
| :--- | :--- |
| [Disclaimer](/legal/disclaimer) | What this site does and does not promise |
| [Copyright and licensing](/legal/copyright) | Ownership of notes, how to report a problem, takedown |

If something here conflicts with a repository's own `LICENSE`, `SECURITY.md`, or
`NOTICE` file, the repository file wins for that repository.
