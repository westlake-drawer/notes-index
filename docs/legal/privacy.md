**处理者。** 本项目的个人信息处理者是 Westlake Drawer 的维护者（学生个人），
不是西湖大学。联系方式见文末。

**本站不收集什么。** 本站是静态站点：没有账号系统、没有分析脚本、没有 Cookie、
没有表单，也不要求你提供任何凭据。

**我们会处理哪些信息。**

| 场景 | 信息 | 是否公开 |
| :--- | :--- | :--- |
| 申请加入组织 | GitHub 用户名；姓名与学校邮箱（通过私下渠道提交） | 用户名在 issue 中公开；姓名与邮箱不公开 |
| 贡献内容 | 提交内容与 git 提交元数据（姓名、邮箱可由你自行设置） | 随仓库公开 |
| 投诉与举报 | 你主动提供的联系方式与证据 | 不公开，仅维护者可见 |
| 访问站点 | IP、User-Agent 由 GitHub Pages 处理 | 组织不持有 |

**目的与依据。** 审核成员资格（基于你的同意）、维护内容与处理投诉（合法利益与法定义务）。
不用于广告、画像或转售。

**公开范围。** 成员申请 issue 默认公开；请在提交前确认。关闭 issue 不会隐藏其中已有的内容。
不要在其中提交电话、密码、验证码或其他敏感信息。

**保存期限。** 成员申请记录在审核结束后保存 12 个月；投诉与处理记录保存 24 个月；
其余信息随 GitHub 仓库的保留策略。超期后删除或匿名化。

**共享与跨境。** 数据保存在 GitHub（美国），属于向境外提供个人信息。本站不使用广告或
数据分析服务。第三方徽章与图片已从索引中移除。

**你的权利。** 你可以查阅、更正、删除个人信息，或撤回同意：通过
[community](https://github.com/westlake-drawer/community) 提出（不要在公开 issue 中写敏感信息），
或联系维护者。我们会在 15 个工作日内答复。撤回同意不影响此前已进行的处理。

**未成年人。** 本站不面向未满 14 周岁的儿童。若你未满 14 周岁，请在监护人同意后再使用或申请。

**安全事件。** 若发生个人信息泄露，我们会在发现后 72 小时内于本站公告，并在可联系到时
通知受影响者，同时说明影响范围与处置措施。

**变更。** 本政策更新后在本页公布并标注日期。

<TabItem value="en" label="English">

Updated 2026-11-25.

**Controller.** The maintainers of Westlake Drawer (individuals), not Westlake
University. Contact details below.

**What the site does not collect.** The site is static: no accounts, no analytics,
no cookies, no forms, no credentials.

**What is processed.**

| Context | Data | Public? |
| :--- | :--- | :--- |
| Membership application | GitHub username; name and school email via a private channel | Username appears in the issue; name and email do not |
| Contributions | Submitted content and git metadata (name/email as you configure them) | Public with the repository |
| Complaints | Contact details and evidence you send | Private, maintainers only |
| Site visits | IP and user agent, processed by GitHub Pages | Not held by the organization |

**Purpose and basis.** Reviewing membership (your consent), maintaining content and
handling complaints (legitimate interests and legal obligations). No advertising,
profiling, or resale.

**Public scope.** Application issues are public by default; check before submitting.
Closing an issue does not hide existing content. Never submit phone numbers,
passwords, verification codes, or other sensitive data.

**Retention.** Application records 12 months after review; complaint records 24
months; the rest follows GitHub's repository retention. Expired data is deleted or
anonymised.

**Sharing and transfers.** Data is stored on GitHub (United States), which is a
transfer of personal information abroad. No advertising or analytics services are
used; third-party badges and images have been removed from the index.

**Your rights.** Access, correction, deletion, or withdrawal of consent: raise it in
[community](https://github.com/westlake-drawer/community) without sensitive details,
or contact a maintainer. We reply within 15 working days. Withdrawal does not affect
processing already carried out.

**Children.** The site is not directed at children under 14. If you are under 14,
use it or apply only with guardian consent.

**Incidents.** On a personal-data breach we publish a notice here within 72 hours of
discovery, notify affected people where we can reach them, and state the scope and
remedy.

**Changes.** Updates are published here with a date.
