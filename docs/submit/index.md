# <Bi en="Submit a resource" zh="提交资源" />

<Bi en="This site is an index. It links to repositories that other people maintain; it does not host files. Submitting means asking us to **list your repository**, not to upload it." zh="本站是索引。它链接到由他人维护的仓库，本身不托管文件。提交的意思是**请我们收录你的仓库**，而不是上传文件。" />

<SubmitButtons />

## <Bi en="What we list" zh="我们收录什么" />

- <Bi en="Course notes for a course at Westlake University, kept in a **public** GitHub repository." zh="西湖大学某门课程的笔记，放在**公开**的 GitHub 仓库里。" />
- <Bi en="A tool you maintain, or one whose author has agreed to be listed." zh="你自己维护的工具，或作者同意被收录的工具。" />

## <Bi en="What we do not list" zh="我们不收录什么" />

- <Bi en="Problem sets, solution keys, or past exam papers." zh="题集、答案册与往年试题。" />
- <Bi en="Instructor slides, handouts, or recordings uploaded without written permission." zh="未经书面许可上传的教师课件、讲义或录音。" />
- <Bi en="Private repositories, credentials, or anything containing personal data." zh="私有仓库、凭据，或任何含个人数据的内容。" />

## <Bi en="Check before you submit" zh="提交前请确认" />

<Bi en="Your repository should already have:" zh="你的仓库应当已经具备：" />

- <Bi en="a `LICENSE` file with a named licence (MIT and CC BY are common; 'no licence' means nobody may reuse it);" zh="带有明确许可的 `LICENSE` 文件（常见的是 MIT 与 CC BY；没有许可意味着任何人都不能二次使用）；" />
- <Bi en="a `README.md` that says what the notes cover and how to build or read them;" zh="说明内容范围与编译/阅读方式的 `README.md`；" />
- <Bi en="sources plus, where possible, a compiled PDF;" zh="源文件，并尽量附上编译好的 PDF；" />
- <Bi en="no personal data: no student IDs, no email lists, no grades." zh="不含个人数据：没有学号、邮箱名单与成绩。" />

<Bi en="If the notes follow a course, name the course and the term (for example, *Calculus, 2025–2026*) so we can place them under the right subject." zh="如果笔记对应某门课，请写明课程与学期（例如 *Calculus, 2025–2026*），方便我们放到正确的学科下。" />

## <Bi en="What happens next" zh="接下来会发生什么" />

1. <Bi en="You open a submission issue with the link and a one-line description." zh="你提交一个 issue，附上仓库链接与一句话说明。" />
2. <Bi en="A maintainer checks the repository against the list above — usually a few days." zh="维护者对照上面的清单检查仓库，通常需要几天。" />
3. <Bi en="If it fits, we add a page under the matching subject and link back to your repository. If it does not, we say which item it failed on." zh="符合要求的话，我们会在对应学科下新增页面并回链到你的仓库；不符合时会说明卡在哪一条。" />

<Bi en="Maintainers are students doing this in their own time; nothing here is a service-level promise. Corrections and updates afterwards go through the same issue." zh="维护者是利用自己时间做这件事的学生，这里没有任何服务等级承诺。之后的更正与更新同样走 issue。" />
