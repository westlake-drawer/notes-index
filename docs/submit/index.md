# Submit a resource

This site is an index. It links to repositories that other people maintain; it does not
host files. Submitting means asking us to **list your repository**, not to upload it.

<SubmitButtons />

## What we list

- Course notes for a course at Westlake University, kept in a **public** GitHub repository.
- A tool you maintain, or one whose author has agreed to be listed.

## What we do not list

- Problem sets, solution keys, or past exam papers.
- Instructor slides, handouts, or recordings uploaded without written permission.
- Private repositories, credentials, or anything containing personal data.

## Check before you submit

Your repository should already have:

- a `LICENSE` file with a named licence (MIT and CC BY are common; "no licence" means
  nobody may reuse it);
- a `README.md` that says what the notes cover and how to build or read them;
- sources plus, where possible, a compiled PDF;
- no personal data: no student IDs, no email lists, no grades.

If the notes follow a course, name the course and the term (for example, *Calculus,
2025–2026*) so we can place them under the right subject.

## What happens next

1. You open a submission issue with the link and a one-line description.
2. A maintainer checks the repository against the list above — usually a few days.
3. If it fits, we add a page under the matching subject and link back to your repository.
   If it does not, we say which item it failed on.

Maintainers are students doing this in their own time; nothing here is a service-level
promise. Corrections and updates afterwards go through the same issue.

## Rights

By submitting you confirm you have the right to publish the content, and you accept the
[contributor licence](/legal/cla). Notes that reproduce instructor material without
permission will be removed on request — see [takedown](/legal/takedown).
