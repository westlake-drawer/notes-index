# Umbra Sentry

<div className="repo-meta"><span>Plugin</span><span>Python</span><span>v1.0.0</span><span>Security</span></div>

[**umbra-sentry**](https://github.com/JiamingShi-JsPhys/umbra-sentry) hardens your own release artifacts against AI reverse-engineering agents. A poisoned analyst burns tokens on canaries, drowns in budget breakers, and reconstructs shadow decoys — while every action it takes is typed, gated, and exportable to OCSF and Sigma.

It is built as an agent plugin: defense here is not obfuscation but semantic deception, deterministic chaining, and decoupled response. Five strategies and two adapters are included.

> **Notice.** A community plugin by Jiaming Shi, not affiliated with Westlake University. Use it only on artifacts you own or are authorized to protect. It runs with your own user privileges once installed — review the code before use. See [Security](/legal/security).
