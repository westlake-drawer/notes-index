# Security Policy

## Reporting a vulnerability

Report privately through GitHub's **Report a vulnerability** on the affected
repository, or contact a maintainer through the organization page. Do not open a
public issue with reproduction steps.

We acknowledge within 72 hours. After a fix, we publish a summary without
reproduction details.

## Scope

- This repository: content structure, frontmatter handling, and links.
- The site engine: <https://github.com/westlake-drawer/westlake-drawer.github.io>.
- Listed tools live in their own repositories and are not audited here; report to
  their authors.

## What this repository never collects

No credentials, no API keys, no personal data beyond what contributors choose to
publish. Never commit secrets; if one is committed, treat it as compromised and
rotate it.
